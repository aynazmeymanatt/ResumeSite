# رزومه‌ی آنلاین آیناز میمنت

سایت رزومه با React + Vite، تم شیشه‌ای/کهکشانی (Glassmorphism + Galaxy)، کاملاً ریسپانسیو و با موشن‌های نرم و مینیمال.

## اجرا روی سیستم خودت

```bash
npm install
npm run dev
```

سایت روی `http://localhost:5173` بالا میاد.

## گرفتن خروجی نهایی برای هاست

```bash
npm run build
```

خروجی نهایی داخل پوشه‌ی `dist/` ساخته می‌شه؛ همین پوشه رو باید روی هاست/دامینت آپلود کنی.

## ویرایش محتوا

تمام متن‌ها (نام، مهارت‌ها، تجربه‌ها، پروژه‌ها، اطلاعات تماس) توی یک فایل جمع شده:

```
src/data/resumeData.js
```

هر چیزی خواستی عوض کنی (مثلاً لینک لینکدین که فعلاً `#` گذاشته شده)، همین فایل رو ویرایش کن.

## عکس پروفایل

فعلاً به‌جای عکس، یه آواتار حرف‌نگار (آم) با افکت مداری گذاشته شده. اگه خواستی عکس واقعی بذاری:
1. عکس رو با نام `avatar.jpg` داخل پوشه‌ی `src/assets/` بذار (این پوشه رو خودت بساز).
2. توی `src/components/Hero.jsx` تگ `<span>آم</span>` رو با `<img src={avatar} alt={profile.nameEn} />` جایگزین کن و بالای فایل `import avatar from "../assets/avatar.jpg";` اضافه کن.

## خرید دامین .ir و آنلاین کردن سایت

1. **ثبت دامین .ir**: باید از طریق مرکز ثبت دامنه‌ی ایران (nic.ir) یا یکی از نمایندگی‌های رسمی‌شون (مثل ایرنیک، پارس‌پک، آنی‌هاست و...) اقدام کنی. برای ثبت دامین .ir معمولاً کد ملی لازمه.
2. **هاست رایگان و ساده** (اگه فعلاً نمی‌خوای هزینه‌ی هاست بدی):
   - **Vercel** یا **Netlify**: پوشه‌ی پروژه رو به گیت‌هاب پوش کن، بعد پروژه رو به Vercel/Netlify وصل کن؛ خودش build و دیپلوی می‌کنه.
   - بعد از دیپلوی، توی تنظیمات دامین (nic.ir یا نمایندگی‌ت) رکوردهای DNS (معمولاً CNAME یا A) رو به آدرسی که Vercel/Netlify بهت می‌ده وصل کن.
3. **هاست ایرانی**: اگه هاست ایرانی (لینوکس، اشتراکی) گرفتی، کافیه محتوای پوشه‌ی `dist/` بعد از `npm run build` رو داخل `public_html` آپلود کنی.

اگه بخوای، مرحله‌ی دیپلوی روی Vercel یا وصل کردن DNS رو هم قدم‌به‌قدم برات توضیح می‌دم.
